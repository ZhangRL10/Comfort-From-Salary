# Comfort-From-Salary - 胧月版

一款 Windows 11 和 macOS 本地收入陪伴工具，让工作时间对应的收入增长变得直观。

我们为打工人制作了一款能够实时显示当日所赚薪资的软件，作为上班的些许安慰~

此外，我们为本项目单独设计了一款桌宠形象--胧月，支持不同时间下的不同状态展示与偶发动作，确保不占用过多桌面空间

Windows x64 试用版支持桌宠悬浮、拖动、置顶、缩放和系统托盘。

桌宠形象设计与动画制作 均由Codex协助完成
## Windows 11 试用版

在 [发布页](../../releases) 的 Assets 区下载 Windows 11 x64 免安装包。

1. 解压 `.zip`文件，在解压后的文件夹中双击 `Comfort-From-Salary.exe`。程序和同目录的文件一起运行。
2. 在「薪资与作息」填写设置，点击「切换桌宠」。桌面版默认按本机时间计算。
3. 拖动胧月调整位置，双击打开完整窗口。右键选择「调整桌宠大小」可用滑条在 50% 至 125% 之间调节。通知区域的 Comfort 图标可以恢复窗口、重置桌宠位置或退出。

此试用版尚未做代码签名。

## macOS 试用版

macOS 桌面版支持 Apple Silicon（`arm64`）和 Intel（`x64`）。用与本机架构匹配的 Node.js 22.12 或更新版本，在项目目录运行以下命令。

```sh
npm ci
npm run desktop
npm run package:mac
```

`npm run package:mac` 在 `dist/` 生成 `Comfort-From-Salary-<版本>-mac-<架构>.zip`。解压后双击 `Comfort-From-Salary.app`。打包使用 ad hoc 签名。下载的试用包可能因未做 Apple 公证而被系统拦截，这时可以在本机构建和运行。

在「薪资与作息」填写设置，再点击「切换桌宠」。桌宠支持拖动、双击恢复完整窗口及右键调整大小和置顶。点击 macOS 菜单栏中的 Comfort 图标可恢复窗口、显示桌宠、重置位置或退出，也可以通过 Dock 恢复隐藏的窗口。

## 打开原型

双击根目录中的 `Open-Prototype.cmd`，或直接用 Edge、Chrome 打开 [`prototype/index.html`](prototype/index.html)，不需要安装依赖，不需要联网。

也可以在项目目录运行 `npm start`，然后访问 `http://127.0.0.1:4173`。此方式需要本机安装 Node.js。

## 当前功能

- 统一界面展示本日已赚、本月已赚，以及月薪、日薪、时薪和秒薪。
- 输入一种薪资，自动换算其余金额；勾选每周工作日，设置统一上下班和午休时间。
- 在**04：本月请假与调休/加班**点击日期，设置全天或半天请假、带薪/不带薪假、调休/加班或调休休息。
- 月历在本地生成，不依赖日历库或网络。
- 每项日期调整支持 **A 默认规则**，或 **B 自定义当天总薪资**；保存前可查看本月预计收入，使用“保存并预览当天”查看该日期及桌宠状态。
- 用顶部“预览状态”查看未上班、计薪中、午休、已下班和休息日，也可以切换到本机时间。
- 切换到桌宠，计薪期间头顶持续显示本日金额；悬停或单击查看本日和本月金额。
- 拖动桌宠；双击或按 Enter 回到完整窗口；右键或 Shift+F10 打开菜单，调整大小、置顶、隐藏或退出。
- 点击预览桌面底部的 Comfort 图标恢复隐藏的窗口或桌宠。
- 拖动窗口标题栏或右下角调整窗口位置、大小。

## 胧月：未上班动画

打开 [`prototype/yueya-before.html`](prototype/yueya-before.html) 可独立预览，支持播放偶发动作、暂停、减少动画，以及切换浅色/深色背景。无须联网或安装依赖。

- 常驻循环约 3 秒：疲惫通勤，手握扶手，另一手提公文包，轻微呼吸和晃动。
- 偶发动作约 3.05 秒：打盹、失衡、重新抓稳扶手、松一口气，再回到常驻姿势。
- 原型内在“预览状态”选择“未上班”，再切换桌宠即可查看。偶发动作每隔 30～90 秒随机播放，也可以右键选择“播放通勤小动作”。
- 切换状态、隐藏桌宠或页面不可见时停止播放；尊重系统的“减少动态效果”设置。
- 这版以 16 张不同的关键帧制作，常驻姿势有 4 张，偶发动作有 12 张；通过播放时长和复用组织节奏，不等同于 60 张逐帧精修稿。

动画文件位于 `prototype/assets/yueya/before/`：`idle.gif`、`doze-recover.gif`、`commute-demo.gif` 及对应的透明 WebP；`frames/` 为 512 × 512 透明 PNG 序列，`commute-sheet-v2.png` 为运行用图集。

胧月动画由参考图衍生的关键帧制作。仓库提供应用运行和预览所需的图集及动画文件。

## 计算规则

所有金额均为按计划工作时间推算的估算值，不识别实际出勤。

- 时薪输入：秒薪 = 时薪 ÷ 3,600。
- 日薪输入：秒薪 = 日薪 ÷ 每个完整工作日的有效计薪秒数。
- 月薪输入：基础秒薪 = 月薪 ÷ 每周基础工作制生成的当月计划计薪总秒数。日期调整不会改变这个分母。
- 其余薪资统一由秒薪换算：时薪 = 秒薪 × 3,600；日薪 = 秒薪 × 标准工作日有效秒数；月薪 = 秒薪 × 当月计划计薪总秒数。
- 本日、本月已赚分别汇总今天零点、本月一日零点至当前时刻已过去的计薪时段，使用每个日期对应的基础或自定义秒薪；包括首次打开软件前已经过去的计划时段。
- 工作安排每周重复。支持跨午夜班次；本日与本月金额按自然日期边界拆分。未计薪午休不增长，带薪午休继续增长。
- 日期调整优先于每周安排，并按完整年月日保存。A 默认不带薪假扣除对应计薪时段，带薪假保留原计划计薪；调休/加班按普通秒薪计入，不自动计算加班倍数；调休休息默认不计薪。
- 半天按一个标准工作日有效计薪时长的 50% 划分为前半班/后半班，不固定以中午为界。
- B 自定义金额是当天的**总计薪金额**，不是原薪资之外的额外奖金。按当天原计划计薪时段分摊；选择半天请假时也代表整天总额，并包含请假时段。跨午夜班次按开班日期设置，收入按自然日/月边界拆分。
- 月薪、日薪、时薪标题带有“· 基础薪资”，秒薪标题带有“· 当前计薪速度”。自定义计薪期间秒薪卡片显示当天实际速度，已赚与预计金额按每个日期的规则计算。
- 工作日选择调休/加班不会在原日薪上重复增加工资。需要额外计薪时，选择 B，输入包含原日薪在内的当天总金额；编辑区展示“原日薪 → 调整后当天总额”。
- 修改过去日期会重新计算已赚收入；未来日期只影响本月预计，尚未经过的时间不会提前计入已赚。选择“按每周工作制”可撤销该日调整；取消设置不保存草稿。
- 不联网识别法定节假日及官方调休，不计算税费。
- 月中修改基础薪资同样按新设置重算当前显示日期所属的整个月，不按修改日期分段计薪。原型没有独立的历史工资账本。

## 本地数据与隐私

原型的薪资、作息、日期调整与桌宠大小通过浏览器本地存储保存。不发送数据，不加载远程字体、图片或脚本。清理浏览器数据可能删除设置；不同浏览器、文件地址与本地预览地址之间不共享设置。请用示例金额体验原型即可。

桌面版将设置保存在当前用户的应用数据目录。桌面版与浏览器原型各自保存设置。

## 开发与验证

桌面版使用 Electron 运行现有 HTML、CSS 和 JavaScript。在 Windows x64 上使用 Node.js 22.12 或更新版本运行以下命令。打包文件生成在 `dist/`。macOS 的构建命令见上面的 macOS 试用版一节。

```sh
npm ci
npm run desktop
npm run package:win
```

计薪测试和浏览器原型分别用以下命令运行。

```sh
npm test
npm start
```

`npm test` 验证计薪边界、午休、周末、带薪/不带薪假、半天假、调休/加班、自定义金额、跨午夜及跨月等规则。

`scripts/check-prototype.cjs` 是可选的界面检查脚本，需要另行准备 Playwright 和 Edge，运行时使用 `CFS_PLAYWRIGHT_MODULE`、`CFS_BROWSER_EXE` 指定本机路径。
